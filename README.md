# ClipShot 내려받기

화면 캡처·복사 목록·이미지 편집 도구 ClipShot의 설치 파일만 올리는 곳입니다. 코드는 여기에 없습니다.

**[최신 버전 내려받기 →](../../releases/latest)**

| | 파일 |
|---|---|
| Windows 10·11 | `ClipShot-버전-windows-setup.exe` |
| Mac (macOS 13 이상, 애플 실리콘·인텔) | `ClipShot-버전-mac.dmg` |

## 설치

- **Windows:** 설치 파일을 실행하면 됩니다. 관리자 권한은 필요 없습니다. 켜져 있는 ClipShot 위에 그대로 설치해도 복사 이력과 설정은 남습니다.
- **Mac:** DMG를 열어 ClipShot을 응용 프로그램 폴더로 끌어 놓습니다. 처음 열 때와 새 버전으로 바꾼 뒤에는
  시스템 설정 → 개인정보 보호 및 보안 → 화면 및 시스템 오디오 녹음에서 ClipShot을 켜 주세요. 자세한 방법은 DMG 안의 "처음 실행 방법.txt"에 있습니다.

## 자동 업데이트

ClipShot은 하루에 한 번 이 저장소의 최신 릴리스를 확인합니다(설정 → 일반에서 끌 수 있습니다).
Windows는 알림을 누르면 받아서 조용히 설치하고 다시 켜집니다. Mac은 DMG를 받아 열어 줍니다.

## 서명

설치 파일마다 `.sig` 서명 파일이 함께 올라갑니다. 앱은 받은 파일이 ClipShot 배포자의 키로 서명된 것일 때만 설치합니다.
이 저장소에 누가 다른 파일을 올리더라도 서명이 맞지 않으면 설치되지 않습니다.
